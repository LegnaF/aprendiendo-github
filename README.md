# Aprendiendo GitHub

Repositorio académico creado para aprender y practicar el uso de **Git y GitHub** durante el proceso de formación en Análisis y Desarrollo de Software.

##  Presentación

Este repositorio contiene diferentes ejercicios, evidencias y proyectos realizados durante el proceso de aprendizaje de Git y GitHub.

##  Objetivos

* Aprender a utilizar Git.
* Aprender a utilizar GitHub.
* Crear y administrar repositorios.
* Realizar commits correctamente.
* Trabajar con ramas.
* Utilizar Git para controlar versiones.
* Organizar proyectos de software.
