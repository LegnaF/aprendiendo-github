# Evidencias

En esta carpeta se almacenan las evidencias correspondientes a las actividades realizadas durante el proceso de aprendizaje de Git y GitHub.

Las evidencias pueden incluir capturas de pantalla de:

* Creación del repositorio.
* Configuración de Git.
* Uso de comandos Git.
* Realización de commits.
* Creación de ramas.
* Uso de GitHub.
* Publicación de proyectos.

Estas evidencias permiten demostrar el desarrollo de las actividades propuestas.
