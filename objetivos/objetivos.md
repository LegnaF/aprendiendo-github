# Objetivos

## Objetivo general

Aprender a utilizar Git y GitHub para gestionar, organizar y controlar las versiones de diferentes proyectos de software.

## Objetivos específicos

* Crear y administrar repositorios.
* Aprender los principales comandos de Git.
* Realizar commits con mensajes claros.
* Trabajar con ramas.
* Aprender a realizar merges.
* Subir y descargar cambios mediante GitHub.
* Organizar correctamente los archivos de un proyecto.
* Aplicar buenas prácticas de control de versiones.
