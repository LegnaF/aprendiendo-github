# Ejercicio 1: Git básico

## Descripción

En este ejercicio se practicaron los comandos básicos de Git para iniciar un repositorio y controlar los cambios realizados en los archivos.

## Comandos utilizados

```bash
git init
git status
git add .
git commit -m "Primer commit"
```

## Aprendizaje

Aprendí a crear un repositorio local, revisar su estado, preparar archivos y guardar los cambios mediante commits.
