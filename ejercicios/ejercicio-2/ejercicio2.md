# Ejercicio 2: GitHub

## Descripción

En este ejercicio se practicó la conexión entre un repositorio local y un repositorio remoto en GitHub.

## Comandos utilizados

```bash
git remote add origin URL_DEL_REPOSITORIO
git branch -M main
git push -u origin main
```

## Aprendizaje

Aprendí a conectar un proyecto local con GitHub y a subir los archivos utilizando el comando `git push`.
