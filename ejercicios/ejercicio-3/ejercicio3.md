# Ejercicio 3: Trabajo con ramas

## Descripción

En este ejercicio se practicó la creación y utilización de ramas para trabajar con diferentes versiones de un proyecto.

## Comandos utilizados

```bash
git branch
git switch
git merge
```

## Aprendizaje

Aprendí que las ramas permiten trabajar en diferentes partes de un proyecto sin modificar directamente la rama principal. También aprendí a unir los cambios mediante `git merge`.
